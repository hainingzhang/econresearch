# 数据字典

备用数据 `njmin3` 为长格式（820 行 = 410 家门店 × 2 个波次）。原始 Card 公开数据代码本将 `STATE` 定义为 1=NJ、0=PA，并报告就业构成；备用数据提供了其公布的 FTE 构造方法。

| 原始字段 | 分析字段 | 含义 / 规则 |
|---|---|---|
| `nj` | `treat`, `state` | 1 = New Jersey / 处理组；0 = Pennsylvania / 对照组 |
| `d` | `post`, `period` | 0 = 1992 年 2 月（政策前）；1 = 1992 年 11 月（政策后） |
| `fte` | `fte` | FTE 就业：全职员工 + 管理人员 + 0.5 × 兼职员工 |
| `nj` × `d` | `did` | DID 交互项 |
| `d` 内的行顺序 | `restaurant_id` | 每个堆叠波次中稳定的 1--410 位置；已核验每个门店—时期仅一个观测 |
| `bk`, `kfc`, `roys`, `wendys` | controls | 快餐连锁品牌指示变量 |
| `co_owned`, `centralj`, `southj`, `pa1`, `pa2` | controls | 所有制和地理指示变量 |

不对缺失值进行插补。原始数据没有明确的门店标识符；仅在确认每个波次均有 410 行后，才使用有文档说明的基于行顺序的键。
